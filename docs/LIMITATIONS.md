# Известные ограничения

- Диаризация не гарантирует правильное число людей. В коротком трёхголосом Dialogs dev прежний frozen INT8 Nemotron выдал 2 ID и слил двух участниц; на AMI с четырьмя участниками появилось 9 ID. Это известное ограничение выбранной финальной конфигурации.
- Диаризация полностью в production release была проверена коротким одноголосым smoke; многоголосые метрики ниже получены на сохранённых frozen-model runs, а не повторены целиком этой release APK.
- `speaker_id` — временная анонимная метка. Она не определяет личность и может меняться при переходе через внешнее окно 120 секунд.
- Точные таймкоды каждого слова не формируются; JSON содержит границы реплик/turns. Перекрывающиеся слова разных участников могут быть неполными.
- ASR измерен на небольших smoke-наборах. Нулевой WER на одном 17-словном фрагменте не является оценкой точности на произвольном аудио.
- GigaAM — модель ASR с пунктуацией. Отдельной локальной текстовой LLM в APK нет; неоднозначное требование организаторов к «локальной LLM» этим не подтверждено.
- Поставляется только ARM64 APK, `minSdk 30`; тестов на Android 11 и других ABI нет. Проверочное устройство: BRP-NX1 / Android 16.
- Модели исполняются на CPU. GPU/NPU ускорение полного pipeline не заявляется.
- APK подписан локальным Android Debug сертификатом для передачи и sideload; это не подпись магазина приложений.
- В тесты не включены исходные аудио и эталоны; лицензии и attribution перечислены отдельно.
