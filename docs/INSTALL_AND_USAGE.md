# Установка и использование

## Установка APK

1. Передайте на телефон файл `Мой стенограф.apk`.
2. Откройте его через приложение «Файлы» и подтвердите установку. Если Android попросит, временно разрешите установку приложений из этого источника.
3. Откройте «Мой стенограф». Для расшифровки файл выбирается через системный экран Android.

Установить с подключённого компьютера можно командой:

```powershell
adb install -r ".\artifacts\Мой стенограф.apk"
```

Требуется Android 11 или новее, ABI `arm64-v8a`. Для обработки аудио Интернет не нужен.

## Расшифровка файла

1. На экране «Записи» нажмите круглую кнопку `+`.
2. Выберите «Добавить аудиофайл» и укажите запись в системном picker.
3. Дождитесь завершения локальной обработки. Во время работы приложение показывает статус задания.
4. Откройте карточку, чтобы прослушать аудио и просмотреть текст с временными границами и метками говорящих.
5. В меню записи нажмите «Экспорт» и выберите TXT или JSON.

Для новой записи нажмите `+` → «Записать разговор» и разрешите доступ к микрофону. После остановки приложение обработает и сохранит стенограмму на этом устройстве.

Приложение принимает аудиоформаты, которые поддерживает системный декодер Android, включая WAV, MP3 и M4A. Длительность и качество обработки зависят от устройства и записи.

## Сборка из исходников

Основной Gradle-проект находится в `android/`. Нужны JDK 17, Android SDK Platform 36 и Build Tools 36.0.0. Команда:

```powershell
cd android
.\gradlew.bat :app:assembleProductionRelease --no-daemon
```

В Git намеренно не включены крупные модельные веса и AAR runtime. До сборки их нужно получить из источников и сверить SHA-256 по [`models/README.md`](../models/README.md); пути по умолчанию задаются в `android/app/build.gradle.kts`. APK финальной проверки подписана локальным Android Debug ключом. Для публикации в магазине используйте release-ключ владельца приложения.
