# Исходный код

Основной Android Gradle проект находится в `android/`:

- `android/app/src/main/` — UI, локальное хранение, обработка заданий, ASR и экспорт.
- `android/app/src/production/` — адаптер Nemotron и production-интеграция.

Экспериментальные bench/MNN варианты остаются локальными и исключены из Git. Сборка и установка описаны в [`docs/INSTALL_AND_USAGE.md`](../docs/INSTALL_AND_USAGE.md).
